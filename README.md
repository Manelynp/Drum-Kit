# Drum Kit

An interactive browser-based drum kit created as part of my learning journey through Angela Yu's Web Development Bootcamp on Udemy.

## 🥁 About the Project

Drum Kit is a small interactive web application that allows the user to play different drum sounds using keyboard keys or by clicking the buttons on the screen.

The project was created to practice JavaScript event handling, DOM manipulation, functions, audio, and user interaction.

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Event Listeners
- Audio
- Git & GitHub

## ✨ Features

- Play different drum sounds by pressing keyboard keys.
- Play sounds by clicking the buttons.
- Provides visual feedback when a drum button is activated.
- Uses JavaScript to respond to user interaction.
- Includes audio files for the different drum sounds.
